ADOFAI 去特效工具  v2.0.0
========================================

一、软件简介
本工具用于清理《冰与火之舞》(A Dance of Fire and Ice) 谱面中的装饰、滤镜、
粒子、屏幕特效等视觉事件，降低游玩卡顿，同时保留玩法判定与输入事件。
本工具为非官方第三方工具，与 7th Beat Games 无关联。

二、系统要求
- Windows 10 / Windows 11（64 位）
- 无需安装 Python，无需安装游戏本体
- 处理时需要能读写谱面文件所在的文件夹

三、快速开始
1. 双击 UI.exe 打开工具。
2. 点击「浏览…」选择要处理的谱面文件（.adofai）。
3. 在「过滤器配置」下拉框选择配置（内置「去除装饰和滤镜」「额外去除轨道颜色」）。
4. 点击「开始处理」，确认后等待完成。
5. 处理完成后，会在原谱面文件同目录生成「原名_配置名.adofai」。
   原谱面文件不会被修改；建议处理前自行备份。

四、过滤器配置
- 点击「管理配置…」打开配置窗口：
  左侧是已保存的配置，右侧预览「留下 / 删除 / 未编辑」三栏事件。
- 新建或编辑配置时，事件以图标形式分三栏显示：
  上左「留下」、上右「删除」、下方「未编辑」。
- 用鼠标把事件图标拖到对应栏即可；三栏之间不会重复。
- 双击「留下」或「删除」里的图标，可以把该事件挪回未编辑。
- 「留下」「删除」右上角的「全部挪回」可以一键清空该栏。
- 未编辑的事件默认保留；全部事件都分到「留下 / 删除」时，
  按「留下」名单处理（白名单），否则按「删除」名单处理。
- 分类按钮与游戏编辑器一致（玩法 / 轨道 / 装饰 / 视效 / 调整 / DLC / 易用性），
  点击分类按钮会定位并高亮该类事件；某分类被全部分完时按钮显示红框提示。
- 新版本事件可在编辑窗口左下角「手动添加事件…」输入英文事件名添加。

五、轨道消失动画
- 位置：主界面「开始处理」右侧。
- 只有当前配置的「留下」栏里有「设置轨道动画」(AnimateTrack) 时才可用。
- 选项：不修改（默认）/ 无 / 收缩 / 暗淡。
- 选择后会将该谱面中所有「开启了轨道消失动画」的事件统一改为所选动画；
  原本就是「无」或没有该选项的事件保持不动，其他字段不受影响。
- 右侧「?」按钮可查看提示。

六、杂项设置
- 显示中文事件名：切换事件图标下显示中文名或英文名。
- 运行结束后自动关闭程序。

七、常见问题
Q：窗口跑到屏幕外 / 界面布局异常？
A：关闭程序后删除 ui_state.json，再重新打开。
Q：处理后游戏里没有变化？
A：确认处理的是输出文件（原名_配置名.adofai），并用它替换原谱面后再游玩。
Q：提示找不到输出文件？
A：确认谱面所在文件夹有写入权限，且 level.exe 与 UI.exe 在同一目录。
Q：杀毒软件误报？
A：本程序使用 PyInstaller 打包，部分杀毒软件可能误报，请添加信任后使用。

八、文件说明
UI.exe          主程序
level.exe       谱面过滤核心程序
events.txt      事件列表（英文名 + 中文名）
levelsset.txt   过滤器配置（保存你的自定义配置）
options.txt     程序设置
ui_state.json   窗口位置记录（自动生成，可删除）
使用说明.txt    本文件

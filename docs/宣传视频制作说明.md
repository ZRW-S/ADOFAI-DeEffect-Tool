# 宣传视频制作说明（给视频生成 AI）

> 下面这份是软件方给视频制作者的完整资料，可以直接作为视频生成的输入。

## 一、软件基本信息
- 名称：**ADOFAI 去特效工具**（版本 v2.0.0）
- 作者：**Zrw**
- 性质：免费、非官方第三方工具，与 7th Beat Games 无关联
- 适用游戏：《冰与火之舞》(A Dance of Fire and Ice / ADOFAI)
- 平台：Windows 10 / 11 64 位
- 形式：安装版（exe，约 48MB）+ 绿色版（zip，约 29MB，解压即用）
- 界面语言：中文（可切换显示中文/英文事件名）

## 二、它是什么、能干什么
用于**一键清理 ADOFAI 谱面里的视觉特效事件**（装饰、滤镜、粒子、屏幕特效等），
降低游玩卡顿，同时**保留玩法判定、输入事件和轨道逻辑**。

处理方式：选择谱面 → 选择过滤器配置 → 开始处理 → 在同目录生成
`原名_配置名.adofai` 的新谱面，**原谱面不会被修改**。处理前建议备份。

## 三、主要功能（可用于视频分镜/字幕）
1. **一键去特效**：内置两个配置「去除装饰和滤镜」「额外去除轨道颜色」，也可自定义。
2. **过滤器配置编辑器**：三栏「留下 / 删除 / 未编辑」，事件以图标展示；
   分类和图标顺序与游戏编辑器一致（玩法 / 轨道 / 装饰 / 视效 / 调整 / DLC / 易用性）。
3. **拖拽式编辑**：拖动图标在栏间移动、双击挪回未编辑、一键「全部挪回」；
   某分类被全部分完时按钮显示红框提示。
4. **支持新版本事件**：游戏 3.4 新增 15 个事件全部支持，包括
   预设高级滤镜 SetFilterAdvanced、粒子发射器/设置粒子/发射粒子、
   设置输入事件 SetInputEvent、设置游戏音效、播放自定义音效、立即失败、
   护盾玩家、设置格子图标、添加组件、呼叫方法、改变轨道、多次点击、方块尺寸。
5. **轨道消失动画统一设置**：当配置的「留下」里有「设置轨道动画」(AnimateTrack) 时，
   可把谱面里所有已开启的轨道消失动画统一改成 **无 / 收缩 / 暗淡**（默认不修改）；
   原本没有开启消失动画的事件保持不动。适合“打过的轨道炸得到处都是”的情况。
6. **处理完成后可直接打开输出目录**；可设置处理完自动关闭程序。
7. **窗口记忆**、**关于窗口**、**安装/卸载程序**，整体是正式软件形态，不是脚本工具。

## 四、真实实测数据（视频里可用的干货，避免夸大 FPS）

|---|---|---|---|

> 可以说“事件量大幅减少，卡顿明显缓解”这类可验证的表述。

## 五、优点（宣传点）
- 免费、体积小、离线可用，不需要安装游戏本体
- 中文界面，分类/图标与游戏编辑器一致，上手快
- 只删视觉事件，**保留玩法判定与输入事件**（不会把谱面改坏）
- 支持最新版本事件，不会因为新谱面用新事件就失效
- 自定义配置可保存复用，处理前不动原文件，安全可反悔
- 安装版 / 绿色版两种形式，分享方便

## 六、限制与注意事项（视频避免虚假宣传）
- 非官方工具，不要声称官方合作
- 只处理视觉类事件，音频/判定/输入不受影响
- 不提供自动更新；处理前需自行备份
- 没有内置游戏录屏功能，宣传素材需要用界面截图 + 数据对比 + 谱面效果

## 七、之前给定的视频要求（必须遵守）
1. 时长：**60–90 秒**，快节奏剪辑（上一版为 86 秒）
2. 风格：**轻松整活 + 干货**，B 站受众，不要官方发布会腔调
3. 声音：**纯字幕 + BGM，无人声旁白**；BGM 为程序生成的科技感轻电子、免版权
4. 内容必须包含：**处理前后对比 + 使用教学 + 新版本事件支持**
5. 成片：直接可发布的 **MP4**，横屏 **1920×1080**，30fps，H.264 + AAC
6. 字幕：中文硬字幕（如平台支持也可附带外挂 SRT）
7. 不伪造游戏实机画面：没有录屏时用数据对比 + 工具界面截图/动画表现
8. 成品另出一张 **1920×1080 封面**，并给 B 站标题、简介、标签建议
9. 视频/封面作者名统一写 **Zrw**（旧版曾用“Zrw的蓝色大肥鱼”，请勿再用旧名）
